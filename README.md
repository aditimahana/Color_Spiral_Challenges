# Color Spiral Challenges 🎨

A collection of three Python Turtle graphics challenges from *Teach Your Kids to Code*. These programs build upon colourful geometric spirals by introducing custom colour palettes, user input, adjustable polygon side counts, and different spiral patterns.

## 🖥️ Programs

| File | Description |
|---|---|
| `color_spiral_challenge1.py` | Creates a ten-sided colourful spiral using a custom ten-colour palette. |
| `color_spiral_challenge2.py` | Allows users to enter a number of sides between 2 and 6 to customise their spiral. |
| `color_spiral_challenge3.py` | Allows users to enter a number of sides between 2 and 10 and adds an extra 90° rotation to create a different pattern. |

## 🛠️ Concepts Used

- Python Turtle Graphics
- `for` loops and `range()`
- User input with `input()`
- Variables and mathematical expressions
- Lists and list indexing
- Modulo operator (`%`)
- Polygon geometry and rotation
- Dynamic pen colours and line widths

## 🚀 How to Run

Make sure Python is installed, then run any of the files:

```bash
python color_spiral_challenge1.py
```

For the second and third challenges, enter the requested number of sides when prompted.

## 🎨 Challenges & Experimentation

These challenges explore how user input and small changes to mathematical expressions can transform a spiral's appearance. Experiment with different side counts, rotation angles, and colour combinations to create your own designs.
